Redmi 5 (rosy) Manifest
=======================

How to use
----------
Clone this repo
```bash
git clone -b afterlife-7 --single-branch https://github.com/aepranata/local_manifests.git .repo/local_manifests
```

Then sync your rom source
```bash
repo sync -c --no-clone-bundle --no-tags --optimized-fetch --prune --force-sync -j8
```
